# 时序裁决器

<ItemImage id="time_heals:verdict_device" scale="3" />

3×3 的一次性仪式装置，用来处理**混沌守卫**：锁定目标、逐颗打掉守卫水晶、蓄能、最后把守卫连同护盾一起裁决。

## 属性

| 项目 | 数值 |
| --- | --- |
| 占地 | 3×3（中心 1 格是控制器，其余 8 格自动生成不可见结构块补碰撞） |
| 硬度 / 抗性 | 5 / 6 |
| 挖掘工具 | 铁镐及以上 |
| 亮度 | 0（只有模型水晶自发光） |
| 音效 | 紫水晶 |
| 寿命 | 一次性，仪式结束后自毁为**哭泣的黑曜石** |

## 启动方式

1. 把机器放在混沌岛上的任意位置；
2. 主手持有**一整组（64 个）时间水晶**；
3. 右键**机器任意部位**（控制器或 3×3 底座任意一格）。

> 创造模式不消耗水晶；生存模式会扣掉 64 个。

## 仪式流程（约 47 秒）

| 阶段 | 时长 | 表现 |
| --- | --- | --- |
| 破晶 | 35 秒 | 四根柱子用光点串连接混沌水晶，连接约 2 秒后水晶爆炸；每破一颗柱子亮起一层环，共 14 层 |
| 蓄能 | 5 秒 | 四柱顶端向中央水晶汇聚能量束 |
| 锁定 | 5 秒 | 中央水晶向混沌守卫发射追踪光束（岛上 256 格内可锁定） |
| 攻击 | 5 tick | 尖啸音波飞向守卫，造成一次混沌级伤害（50000，足以连 16000 护盾与 1000 本体一起打掉） |
| 收尾 | 2 秒 | 进度保持满格，随后机器自毁 |

## 阶段提示

- 底盘那一圈槽是**进度条**：从绿色逐渐变成大红色；
- 柱子上的圆环按破晶层数点亮，颜色同样由绿到红；
- 开启字幕后，右下角会显示「时序裁决器：破晶 / 蓄能 / 锁定 / 攻击 / 裁决」以及「混沌水晶：爆炸」。

## 注意

- 需要**龙之进化**：目标类型与伤害类型都来自它；
- 附近没有混沌守卫时，仪式的锁定与攻击阶段会空转，但机器照样会消耗；
- 守卫水晶会被逐个真正摧毁，护盾随之下降；
- 只有附近**没有存活水晶**时才会强行处决守卫，否则只造成伤害。

| 角色 | 材料 |
| --- | --- |
| 催化剂 | **神龙之力权杖** ×1 |
| 材料 | 时间水晶块 ×4、**神龙通量容器 ×2（各需 ≥ 320.0 MOP 能量）**、神龙弓 ×2、神龙能量核心 ×2<br>满耐久或**不可破坏**的时间之剑 ×1 |

### 按模组附加材料

配方会随整合包加载的模组自动追加材料（**只加不减**）：

| 额外装载 | 追加材料 |
| --- | --- |
| 数据能源学 | 时间核心 ×4、极限承载接口 ×2 |
| Powah | 下界电容 ×2 |

> 两套附加材料互不排斥：都装时四套配方中只有「全附加」那条生效；
> 只装其中一个时，基础配方会因 `not(mod_loaded)` 条件隐藏，改用对应变体。
