# 2 重压缩时间水晶块

<ItemImage id="kubejs:2x_time_crystal_block" scale="3" />

更深一层的压缩水晶块，物品形态带发光效果。

## 属性

| 项目 | 数值 |
| --- | --- |
| 硬度 / 抗性 | 6 / 15 |
| 挖掘工具 | 铁镐及以上 |
| 亮度 | 7 |
| 音效 | 金属 |
| 特殊 | 物品栏中发光 |

## 用途

- 锻造台升级时间工具的必需材料；
- 挖掘时有概率掉落**时间锻造模板**。
