# 时间工程指南

欢迎来到 **时间工程** 的说明文档。

时间系列装备由整合包的 KubeJS 脚本注册，本模组（`time_heals`）作为前置补上它们做不到的部分：
**混沌级伤害判定**、**时间混乱**效果、**时间加速**，以及一次性装置**时序裁决器**。

## 快速开始

- 把鼠标**悬停**在任意时间系列物品上，**长按** <kbd>G</kbd>（GuideME 默认热键）即可直接跳到对应页面；
- 左侧边栏可以浏览全部章节；
- 按 <kbd>Esc</kbd> 关闭指南。
