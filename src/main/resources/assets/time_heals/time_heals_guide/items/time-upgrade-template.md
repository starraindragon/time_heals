# 时间锻造模板

<ItemImage id="kubejs:time_upgrade_template" scale="3" />

用于在锻造台把时间系列工具升级为**不可损坏**版本。

## 获取

挖掘**2 重压缩时间水晶**时有 **10%** 概率掉落。

## 用途

锻造台：`时间锻造模板 + 时间工具 + 2 重压缩时间水晶块` → 不可损坏的时间工具。
