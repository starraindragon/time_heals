# 时间之镐

<ItemImage id="kubejs:time_pickaxe" scale="3" />

时间系列挖掘工具，适合快速开采。

## 基础属性

| 项目 | 数值 |
| --- | --- |
| 材质等级 | 时间水晶（耐久 700 / 挖掘速度 7.3 / 攻击加成 2.6 / 附魔性 16） |
| 修复 | 铁锭 |

## 通用能力

- **混沌级伤害**：主手持有即被龙之进化判定为混沌级，攻击混沌晶体时无视不稳定窗口；
- **时间混乱**：命中生物叠加层数（I / II / III），第 III 层每秒损失当前生命 10%。

详见[混沌级伤害](../mechanics/chaos-damage.md)与[时间混乱](../effects/time-confusion.md)。

## 制作

工作台：**时间水晶块 + 铁锭**；锻造台：用**时间锻造模板**升级为不可损坏版本。
