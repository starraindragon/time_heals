# 时间水晶

<ItemImage id="kubejs:time_crystal" scale="3" />

时间系列的核心材料，通过击杀魔物掉落。

## 掉落来源

| 掉落数量 | 生物 |
| --- | --- |
| 1 个 | 僵尸、骷髅、蜘蛛、洞穴蜘蛛、尸壳、幻翼 |
| 2 个 | 苦力怕、女巫、溺尸 |

## 用途

- 合成**时间水晶块**；
- 作为**时间加速**的消耗品（每次潜行/按键加速消耗 1 个）。
